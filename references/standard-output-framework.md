## 二、各页面内容维度

### 2.1 概览 Dashboard

**页面定位**：绩效目标拆解健康度总览，一眼掌握全局情况。

**副标题格式**：绩效目标拆解健康度总览，覆盖 {N} 个目标 · {N} 名人员 · {N} 个部门

#### 核心指标卡片（6 个，第一行）

| 卡片 | 内容 | 说明 |
|------|------|------|
| **整体健康度** | 环形图 + 分数 + 等级 + 一句话说明 | 等级：优秀(90-100)/良好(70-89)/一般(50-69)/较差(0-49) |
| **目标总数** | 数字 + 单位"个" | 参与诊断的目标总数 |
| **平均完成率** | 百分比 | 所有目标进度的平均值 |
| **问题总数** | 数字 + 环比变化箭头 | 较上周期的变化（+N/-N） |
| **高严重度问题** | 数字 + 环比变化箭头 | 仅统计 high 严重度 |
| **涉及人员** | 数字 + 单位"人" | 有目标的人员数 |

#### 图表区（第二行，3 列）

| 图表 | 类型 | 内容 |
|------|------|------|
| **问题严重度分布** | 环形图 | 高/中/低严重度问题数量占比 |
| **目标完成率分布** | 柱状图 | 按区间：0-40%(落后)、40-60%(滞后)、60-80%(正常)、80-100%(优秀) |
| **各部门问题数量对比** | 柱状图 | 按部门统计问题数，降序排列 |

#### 图表区（第三行，2 列）

| 图表 | 类型 | 内容 |
|------|------|------|
| **六大维度问题数量** | 横向条形图 | 未向上对齐、上下层数据不匹配、层次不准确、责任不清、目标重复、无具体执行人 |
| **各层级问题分布** | 堆叠柱状图 | L1公司级/L2部门级/L3团队级/L4员工级，按严重度堆叠 |

#### 图表区（第四行，2 列）

| 图表 | 类型 | 内容 |
|------|------|------|
| **问题趋势** | 折线图 | 近 4 个周期，高/中/低严重度问题数变化趋势 |
| **TOP5 问题责任人** | 横向条形图 | 问题数最多的前 5 人 |

### 2.2 指标拆解树（v2.6 默认拆解视图）

- 每个指标是独立节点，必须包含指标 ID、名称、值、单位、所属目标、负责人、部门和层级。
- 显式指标关系使用实线，来源为指标字段或 `indicator_relations`。
- 仅在父目标/对齐目标限定候选范围后，才允许用四层语义算法生成推断边；推断边使用虚线，展示关系质量和人工复核提示。
- 缺少指标级关系且语义证据不足时，节点进入“数据缺口”区域，不绘制确定性关系。
- 点击节点展示向上关联、向下承接、四层判断、风险标记、关系来源和证据。
- 保留目标拆解树作为独立页面/切换视图，不再把目标节点内的指标列表称为指标拆解树。

### 2.3 目标拆解树

**页面定位**：4 层目标体系可视化，点击节点查看详情。

**副标题格式**：4 层目标体系可视化（L1公司级 → L2部门级 → L3团队级 → L4员工级），共 {N} 个目标

#### 顶部统计栏

| 元素 | 说明 |
|------|------|
| 层级统计标签 | L1: N个 | L2: N个 | L3: N个 | L4: N个（可点击筛选） |

#### 筛选区

| 筛选项 | 说明 |
|--------|------|
| 搜索框 | 搜索目标名称/负责人/指标 |
| 部门筛选 | 下拉选择，默认"全部部门" |
| 层级筛选 | 下拉选择，默认"全部层级" |
| 目标状态筛选 | 下拉选择，默认"全部目标" |

#### 操作按钮

| 按钮 | 说明 |
|------|------|
| 全部展开 | 展开所有目标节点 |
| 全部收起 | 收起所有目标节点 |
| 缩放控制 | 100% / 放大 / 缩小 / 全屏 |

#### 左侧：目标层级拆解树

**节点状态颜色**：

| 状态 | 颜色 | 说明 |
|------|------|------|
| 健康 | 🟢 绿色 | 无问题，进度正常 |
| 正常 | 🟣 紫色 | 低严重度问题，不影响整体 |
| 警告 | 🟡 黄色 | 中严重度问题，需关注 |
| 严重 | 🔴 红色 | 高严重度问题，需立即处理 |

**每个节点显示**：
- 层级标签（L1/L2/L3/L4 + 类型：目标O/KR）
- 目标标题
- 负责人（头像+姓名）
- 指标进度（如：营收 8.25/15亿）
- 展开/收起箭头

#### 右侧：目标详情面板

| 区块 | 内容 |
|------|------|
| **基本信息** | 目标类型(O/KR)、层级、标题 |
| **元信息** | 负责人(头像+姓名+职位)、部门、权重、截止日期 |
| **关键指标摘要** | 指标名称、目标值、当前值、完成率、进度条 |
| **下级目标列表** | 可展开，显示子目标标题和状态 |
| **诊断问题** | 该目标关联的问题列表（可选） |

### 2.4 诊断结果

**页面定位**：六大维度详细诊断，问题清单和证据。

**副标题格式**：六大维度详细诊断，共发现 {N} 个问题

#### 顶部统计栏

| 元素 | 说明 |
|------|------|
| 严重度统计 | 🔴 高: N个 | 🟡 中: N个 | 🟢 低: N个（彩色标签） |

#### 六大维度卡片（可点击筛选）

| 维度 | 图标颜色 | 说明 |
|------|---------|------|
| 上下层数据不匹配 | 🟠 橙色 | 上级目标与下级目标合计数据存在偏差 |
| 无具体执行人 | 🟡 黄色 | 目标缺少明确的负责人或主责人 |
| 目标重复 | 🟣 紫色 | 不同部门/人员设置了高度相似的目标 |
| 责任不清 | 🟦 蓝色 | 目标边界模糊，多人交叉或真空 |
| 未向上对齐 | 🟩 青色 | 下级目标未对齐到任何上级目标 |
| 层次不准确 | 🟪 粉色 | 目标粒度过粗/过细，应上移或下移 |

每个卡片显示：图标 + 维度名称（缩写）+ 问题数量 + 下拉箭头

#### 维度详细列表

每个维度一个区块，包含：

| 元素 | 说明 |
|------|------|
| 维度标题 | 图标 + 维度名称 + 问题数量标签 |
| 维度说明 | 一句话描述该维度的检查逻辑 |
| 问题列表 | 表格或卡片形式 |

**问题表格字段**：

| 字段 | 说明 |
|------|------|
| 严重度 | 🔴高 / 🟡中 / 🟢低（彩色标签） |
| 问题描述 | 简洁的问题标题 |
| 偏差率 | 百分比（红色显示，仅数据不匹配维度） |
| 缺口量 | 数值（仅数据不匹配维度） |
| 相似度 | 百分比（仅目标重复维度） |
| 详情 | 展开按钮，点击显示完整证据和建议 |

**展开详情内容**：
- 完整问题描述
- 证据说明（数据来源、计算逻辑）
- 关联目标
- 改进建议

### 2.5 优化建议

**页面定位**：按责任人分组的行动项清单，推动问题落地解决。

**副标题格式**：按责任人分组的行动项清单，推动问题落地解决

#### 顶部操作栏

| 元素 | 说明 |
|------|------|
| 导出表格按钮 | 导出所有建议为 Excel/CSV |

#### 优先级统计卡片（3 个）

| 优先级 | 颜色 | 说明 |
|--------|------|------|
| **P0 紧急** | 🔴 红色 | 立即处理，N 条 |
| **P1 重要** | 🟡 黄色 | 尽快处理，N 条 |
| **P2 一般** | 🔵 蓝色 | 有空再改，N 条 |

#### 筛选条件

| 筛选项 | 说明 |
|--------|------|
| 优先级 | 全部优先 / P0 / P1 / P2 |
| 维度 | 全部维度 / 具体维度 |
| 责任人 | 全部人员 / 具体人员 |

#### 左侧：按维度统计

| 图表 | 类型 | 内容 |
|------|------|------|
| 按维度统计 | 柱状图 | 各维度优化建议数量分布 |

#### 右侧：行动清单（按责任人分组）

**每个责任人分组**：
- 展开/收起箭头
- 头像 + 姓名
- 建议数量（N 条建议待处理）
- 优先级统计标签（P0 × N, P1 × N）

**每条建议卡片**：

| 元素 | 说明 |
|------|------|
| 优先级标签 | P0(红)/P1(黄)/P2(蓝) |
| 建议内容 | 具体可执行的建议描述（1-2 句话） |
| 关联问题 | ⚠️ 关联问题：{问题标题} |
| 元信息 | 👤 责任人 | 📅 截止日期 | 🏷️ 问题维度标签 |

**副标题格式**：按人员/部门查看目标和问题分布，共 {N} 人

#### 左侧：组织架构树

- 白色背景，12px 圆角

#### 表格
- 表头浅灰背景
- 行高 48px
- 边框线 1px #eee

#### 进度条
- 高度 8px，圆角 4px
- 背景 #eee，前景按状态着色

## 五、输出格式要求

### Markdown 输出
- 按 6 个页面分章节，使用 `##` 标题
- 每个章节内按内容维度使用表格和列表
- 保持结构清晰，可直接粘贴到飞书文档

### HTML 输出
- 模拟左侧导航 + 主内容区的布局，使用 Tab 切换 6 个页面
- 应用上述颜色和布局规范
- 包含简单的图表（可用 CSS 或简单 SVG 实现）

### JSON 输出
- 新增 `standard_framework` 字段，包含 6 个页面对应的数据结构
- 保持向后兼容，原有字段不变
