# 行业指标库 - 变更日志与版本管理

> 本文档记录行业指标库的所有版本变更、指标更新历史和版本管理规则。

---

## 一、版本管理规则

### 1.1 版本号格式

`主版本号.次版本号.修订号`（如 `v2.1.0`）

| 版本类型 | 说明 | 触发条件 |
|---------|------|---------|
| **主版本号（Major）** | 重大架构变更 | 新增≥3个行业、指标体系重构、元数据标准变更 |
| **次版本号（Minor）** | 功能增强和数据更新 | 新增指标、更新基准值、新增管理文档 |
| **修订号（Patch）** | 错误修复和小范围修正 | 修复数据错误、修正元数据、小范围调整 |

### 1.2 版本发布频率

| 版本类型 | 发布频率 | 发布时间 |
|---------|---------|---------|
| 主版本 | 不固定 | 重大变更完成后 |
| 次版本 | 每半年 | 每年1月、7月 |
| 修订版 | 随时 | 发现错误后1周内 |

## 三、指标变更记录模板

每次指标更新时，按以下格式记录：

```
### [指标名称] - [变更日期]
- **变更类型**：新增 / 更新 / 删除 / 修正
- **变更前**：[旧基准值]（数据截止时间：[时间]）
- **变更后**：[新基准值]（数据截止时间：[时间]）
- **偏差**：[偏差百分比]
- **变更原因**：[原因说明]
- **数据来源**：[新来源]
- **验证状态**：已验证 / 待验证
- **责任人**：[维护者]
```

## 四、版本兼容性说明

| 版本 | 向后兼容 | 迁移说明 |
|------|---------|---------|
| v2.1.x | ✅ 完全兼容 v2.0.x | 仅新增元数据字段，不影响现有功能 |
| v2.0.x | ⚠️ 部分兼容 v1.x | 诊断逻辑增强，结果可能有差异 |
| v1.x | ✅ 完全兼容 v1.x | 同主版本内完全兼容 |
