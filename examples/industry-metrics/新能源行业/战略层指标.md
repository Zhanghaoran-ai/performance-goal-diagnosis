## 指标详解

### 1. 容量系数（Capacity Factor）

- **基准值**：25%（光伏）/35%（风电）
- **合理范围**：20%~30%（光伏）/30%~50%（风电）
- **数据来源**：新能源行业通用基准 / 风电光伏技术指标手册
- **权威性**：⭐⭐⭐⭐⭐
- **发布机构**：新能源行业通用基准 / 国家能源局
- **数据截止时间**：2025-12
- **来源链接**：风电光伏技术指标手册 / 国家能源局年度报告
- **稳定性**：较稳定（半年更）
- **验证状态**：✅ 已验证
- **说明**：实际发电量与装机容量满发时发电量的比值，新能源电站核心效率指标

### 2. 系统效率（PR值）

- **基准值**：82%
- **合理范围**：78% ~ 85%
- **数据来源**：IEC 61724标准 / 标杆光伏电站标准
- **权威性**：⭐⭐⭐⭐⭐
- **发布机构**：国际电工委员会(IEC)
- **数据截止时间**：2025-12
- **来源链接**：IEC 61724-1:2021光伏系统性能监测标准
- **稳定性**：稳定（年更）
- **验证状态**：✅ 已验证
- **说明**：光伏系统实际输出与理论输出的比值，独立于辐照的质量指标，IEC国际标准

### 3. 设备可用率

- **基准值**：98%
- **合理范围**：95% ~ 99%
- **数据来源**：Financial Models Lab风电场KPI报告
- **权威性**：⭐⭐⭐⭐
- **发布机构**：Financial Models Lab
- **数据截止时间**：2025-06
- **来源链接**：Financial Models Lab风电场KPI报告
- **稳定性**：较稳定（半年更）
- **验证状态**：⚠️ 待验证
- **说明**：设备可用于发电的时间占总时间的比例，设备可靠性指标

### 4. 置信出力

- **基准值**：6%（光伏）/11%（风电）
- **合理范围**：5%~8%（光伏）/8%~13%（风电）
- **数据来源**：国家十五五新能源规划 / 新型电力系统考核指标
- **权威性**：⭐⭐⭐⭐⭐
- **发布机构**：国家能源局 / 国家发改委
- **数据截止时间**：2026-06
- **来源链接**：国家十五五新能源规划 / 新型电力系统考核指标
- **稳定性**：动态（季更）
- **验证状态**：✅ 已验证
- **说明**：95%置信度下的保证出力占装机容量的比例，新能源从垃圾电到可靠电源的核心考核指标

### 5. 度电成本（LCOE）

- **基准值**：0.3元/kWh
- **合理范围**：0.25 ~ 0.4元/kWh
- **数据来源**：新能源行业基准
- **权威性**：⭐⭐⭐⭐
- **发布机构**：新能源行业基准 / 国际可再生能源署(IRENA)
- **数据截止时间**：2026-06
- **来源链接**：IRENA可再生能源发电成本报告 / 行业基准
- **稳定性**：动态（季更）
- **验证状态**：⚠️ 待验证
- **说明**：全生命周期总成本除以总发电量，经济性核心指标

### 6. 安全事故率

- **基准值**：0.1次/年
- **合理范围**：0 ~ 0.5次/年
- **数据来源**：电力安全生产标准
- **权威性**：⭐⭐⭐⭐
- **发布机构**：国家能源局 / 电力安全生产标准
- **数据截止时间**：2025-12
- **来源链接**：电力安全生产标准化规范
- **稳定性**：稳定（年更）
- **验证状态**：✅ 已验证
- **说明**：电站每年发生的安全事故数量，安全生产核心指标
