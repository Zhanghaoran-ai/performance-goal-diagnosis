# 行业指标库 - 数据质量与元数据标准

> 本文档定义行业指标库的元数据规范、数据质量要求和使用声明。

---

## 一、元数据标准

每个指标必须包含以下元数据字段：

### 1.1 战略层指标元数据

| 字段 | 说明 | 示例 | 是否必填 |
|------|------|------|---------|
| **指标名称** | 指标的标准名称 | OEE（设备综合效率） | ✅ |
| **基准值** | 行业通用基准值 | 65% | ✅ |
| **合理范围** | 正常波动范围 | 60% ~ 85% | ✅ |
| **数据来源** | 数据出处（机构+报告名） | ISO 22400标准 / 麦肯锡制造业研究 | ✅ |
| **发布机构** | 数据发布的权威机构 | ISO国际标准化组织 | ✅ |
| **数据截止时间** | 基准值对应的时间点 | 2026-06 | ✅ |
| **来源链接** | 可溯源的链接或文档编号 | ISO 22400-1:2014 | ✅（无链接时填"公开标准，可官网查询"） |
| **权威性** | 星级评分 | ⭐⭐⭐⭐⭐ | ✅ |
| **稳定性** | 指标变化频率 | 稳定（年更） | ✅ |
| **验证状态** | 数据验证情况 | 已验证 | ✅ |

### 1.2 管理层/执行层指标元数据

| 字段 | 说明 | 示例 | 是否必填 |
|------|------|------|---------|
| **指标名称** | 指标的标准名称 | 产能达成率 | ✅ |
| **基准值** | 行业通用基准值 | 95% | ✅ |
| **合理范围** | 正常波动范围 | 90% ~ 100% | ✅ |
| **对应上层指标** | 支撑的战略层指标 | OEE / 交付周期 | ✅ |
| **数据来源** | 数据出处 | 制造业通用基准 | ✅ |
| **数据截止时间** | 基准值对应的时间点 | 2026-06 | ✅ |
| **稳定性** | 指标变化频率 | 稳定（年更） | ✅ |

---

## 二、稳定性分级

| 等级 | 说明 | 更新频率 | 典型指标 |
|------|------|---------|---------|
| **稳定（年更）** | 指标定义和基准值长期稳定，变化缓慢 | 每年复核一次 | OEE、一次合格率、安全事故率 |
| **较稳定（半年更）** | 指标基准值会随行业发展缓慢变化 | 每半年复核一次 | 库存周转率、订单准时交付率 |
| **动态（季更）** | 指标受技术进步、市场环境影响大，变化快 | 每季度复核一次 | 度电成本、用户增长率、获客成本 |

---

## 三、验证状态定义

| 状态 | 说明 | 标记 |
|------|------|------|
| **已验证** | 基准值有至少2个独立来源交叉验证，数据可靠 | ✅ 已验证 |
| **待验证** | 基准值只有1个来源，或来源权威性不足，需要进一步验证 | ⚠️ 待验证 |
| **参考值** | 基准值为经验估算或行业通用说法，仅供参考 | 📌 参考值 |

---

## 四、数据质量声明

### 4.1 使用声明

> **重要提示**：本指标库的基准值仅供参考，不构成任何决策依据。
>
> 1. 基准值为行业通用水平，不同企业因规模、地域、发展阶段、技术水平等因素会有较大差异
> 2. 部分指标基准值为经验估算或行业通用说法，未经过严格的学术验证
> 3. 快速变化行业（如新能源、互联网）的基准值可能已过时，请以最新行业报告为准
> 4. 建议结合企业自身历史数据和同行业可比公司数据进行综合判断

### 4.2 数据局限性

| 局限性 | 说明 |
|--------|------|
| **行业粒度粗** | 当前"制造业"等分类较粗，未细分到离散制造/流程制造等子行业 |
| **地域差异** | 基准值多为全球或中国平均水平，未区分一线城市/三四线城市 |
| **企业规模差异** | 未区分大型企业/中型企业/小微企业的基准差异 |
| **时间滞后** | 部分数据可能存在6-12个月的滞后 |

## 五、元数据填写指南

### 5.1 数据截止时间填写规范
- 格式：`YYYY-MM`（如 `2026-06`）
- 无法确定精确时间时，填写估计的时间范围，并标注"约"
- 示例：`约2025年`、`2026-Q1`

### 5.2 来源链接填写规范
- 有公开链接的，填写完整URL
- 国际标准填写标准编号（如 `ISO 22400-1:2014`）
- 无公开链接的，填写 `公开报告，可官网查询` 或 `行业内部资料`

### 5.3 发布机构填写规范
- 填写机构全称（如 `国际标准化组织` 而非 `ISO`）
- 多个机构用 `/` 分隔
- 示例：`国际标准化组织 / 麦肯锡公司`
