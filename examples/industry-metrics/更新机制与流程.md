# 行业指标库 - 更新机制与流程

> 本文档定义行业指标库的更新频率、责任人、更新流程和触发机制。

---

## 一、更新频率

### 1.1 按指标稳定性分级更新

| 指标类型 | 更新频率 | 复核时间 | 责任人 |
|---------|---------|---------|--------|
| **稳定指标（年更）** | 每年更新一次 | 每年1月 | 指标库维护者 |
| **较稳定指标（半年更）** | 每半年更新一次 | 每年1月、7月 | 指标库维护者 |
| **动态指标（季更）** | 每季度更新一次 | 每季度首月 | 指标库维护者 |

### 1.2 定期更新时间表

| 时间节点 | 更新内容 | 输出物 |
|---------|---------|--------|
| **每年1月** | 全量复核所有指标，更新稳定指标 | 年度更新报告 + 变更日志 |
| **每年4月** | 更新动态指标（Q1数据） | 季度更新记录 |
| **每年7月** | 更新较稳定指标 + 动态指标（Q2数据） | 半年度更新报告 |
| **每年10月** | 更新动态指标（Q3数据） | 季度更新记录 |

## 二、责任人与角色

### 2.1 角色定义

| 角色 | 职责 | 人数 |
|------|------|------|
| **指标库维护者** | 负责日常维护、定期更新、质量把控 | 1人 |
| **行业专家** | 负责特定行业指标的专业性审核 | 每行业1人（可兼职） |
| **数据贡献者** | 提供行业数据、报告、基准值 | 多人 |
| **用户反馈处理者** | 收集和处理用户反馈，触发更新 | 1人（可与维护者兼任） |

### 2.2 责任矩阵

| 任务 | 维护者 | 行业专家 | 数据贡献者 | 用户 |
|------|--------|---------|-----------|------|
| 定期更新指标 | ✅ 负责 | ✅ 审核 | 📤 提供数据 | - |
| 新增行业/指标 | ✅ 负责 | ✅ 审核 | 📤 提供数据 | 💡 提需求 |
| 处理用户反馈 | ✅ 负责 | ✅ 评估 | - | 📝 提反馈 |
| 质量检验 | ✅ 负责 | ✅ 抽检 | - | - |
| 版本发布 | ✅ 负责 | - | - | - |

## 三、更新流程

### 3.1 定期更新流程

```
1. 启动更新
   ↓
2. 收集最新行业数据和报告
   ↓
3. 对比新旧基准值，计算偏差
   ↓
4. 偏差 < 10%？ → 是 → 直接更新，记录变更
   ↓ 否
5. 偏差 10% ~ 20%？ → 是 → 行业专家审核后更新
   ↓ 否
6. 偏差 > 20%？ → 是 → 多方交叉验证，维护者+专家共同确认
   ↓
7. 更新指标文件，填写元数据
   ↓
8. 更新变更日志
   ↓
9. 发布新版本
```

### 3.2 触发式更新流程

除了定期更新，以下情况会触发即时更新：

| 触发条件 | 响应时间 | 处理方式 |
|---------|---------|---------|
| 用户反馈指标不准（≥3人反馈同一指标） | 2周内 | 核实后更新 |
| 发布重大行业标准/政策 | 1个月内 | 评估影响，必要时更新 |
| 行业发生重大变化（如技术突破、监管变化） | 1个月内 | 评估影响，必要时更新 |
| 发现数据错误 | 立即 | 修正并发布补丁版本 |

## 四、数据收集渠道

### 4.1 权威数据源（优先级从高到低）

1. **国际标准**：ISO、IEC、IEEE 等国际组织发布的标准
2. **国家监管**：国家统计局、行业监管部门发布的官方数据
3. **行业协会**：中国制造业协会、中国汽车工业协会等
4. **权威咨询**：麦肯锡、波士顿、德勤等咨询公司行业报告
5. **上市公司财报**：同行业上市公司的公开财报数据
6. **专业机构**：Gartner、IDC、Canalys 等市场研究机构
7. **企业实践**：头部企业公开的最佳实践数据

### 4.2 数据收集方法

| 方法 | 说明 | 频率 |
|------|------|------|
| **报告检索** | 定期检索行业报告和白皮书 | 每季度 |
| **财报分析** | 分析同行业上市公司财报，计算行业均值 | 每半年 |
| **专家访谈** | 与行业专家交流，获取一手经验数据 | 每年 |
| **用户反馈** | 收集用户对基准值的反馈和修正建议 | 持续 |

## 五、更新质量要求

### 5.1 更新前检查清单

- [ ] 新数据来源是否权威（≥⭐⭐⭐⭐）？
- [ ] 是否有至少2个独立来源交叉验证？
- [ ] 数据截止时间是否明确？
- [ ] 基准值变化是否有合理的行业解释？
- [ ] 是否影响其他关联指标？

### 5.2 更新后验证

- [ ] 指标文件格式是否符合元数据标准？
- [ ] 变更日志是否完整记录？
- [ ] 三层指标之间的对应关系是否一致？
- [ ] 诊断工具是否能正常读取新数据？

## 六、版本号规则

### 6.1 版本号格式

`主版本号.次版本号.修订号`（如 `v2.1.0`）

| 版本类型 | 说明 | 示例 |
|---------|------|------|
| **主版本号** | 重大架构变更、新增大量行业 | v2.0.0 → v3.0.0 |
| **次版本号** | 新增指标、更新基准值、功能增强 | v2.1.0 → v2.2.0 |
| **修订号** | 修复数据错误、小范围修正 | v2.1.0 → v2.1.1 |

### 6.2 发布频率

- **主版本**：不固定，重大变更时发布
- **次版本**：每半年发布一次（与定期更新同步）
- **修订版**：发现错误时随时发布
