# 行业指标库

> ⚠️ **重要数据质量声明**
> 
> 本指标库的基准值**仅供参考**，不构成任何决策依据。
> 1. 基准值为行业通用水平，不同企业因规模、地域、发展阶段、技术水平等因素会有较大差异
> 2. 部分指标基准值为经验估算或行业通用说法，未经过严格的学术验证
> 3. 快速变化行业（如新能源、互联网）的基准值可能已过时，请以最新行业报告为准
> 4. 建议结合企业自身历史数据和同行业可比公司数据进行综合判断
>

## 📋 概述

本行业指标库是绩效目标拆解诊断工具的配套资源，提供各行业的三层绩效指标体系，用于第七大诊断维度——**指标偏离行业基准**的对标分析。

## 🏗️ 三层指标体系框架

| 层级 | 别名 | 面向对象 | 更新频率 | 指标数量 | 核心作用 |
|------|------|---------|---------|---------|---------|
| **战略层** | 公司级/厂级 | 高管、厂长 | 月/季 | 5-8个 | 承接战略，对标行业 |
| **管理层** | 部门级/车间级 | 部门经理、车间主任 | 周/月 | 8-12个 | 分解战略，运营管控 |
| **执行层** | 班组级/岗位级 | 班组长、一线员工 | 日/班 | 5-8个 | 落地执行，日常改善 |

### 层级支持关系

```
战略层（结果指标）
    ↑ 由...支撑
管理层（过程指标）
    ↑ 由...驱动
执行层（动作指标）
```

- **自下而上支撑**：执行层指标 → 驱动 → 管理层指标 → 驱动 → 战略层指标
- **自上而下分解**：战略层目标 → 分解为 → 管理层目标 → 分解为 → 执行层目标
- **因果关系，不是简单拆分**：下层指标是上层指标的驱动因素，不是数字的简单切分

## 📝 指标文件格式

每个指标文件包含以下内容：

### 战略层指标文件
- 指标列表（名称、基准值、合理范围、数据来源、权威性）
- 指标详解（基准值、合理范围、数据来源、权威性、详细说明）

### 管理层/执行层指标文件
- 指标列表（名称、基准值、合理范围、对应上层指标）
- 指标详解（基准值、合理范围、对应上层指标、详细说明）

## 🏆 权威性分级

| 星级 | 说明 | 典型来源 |
|------|------|---------|
| ⭐⭐⭐⭐⭐ 非常权威 | 国际标准 / 学术综述 / 行业强制标准 / 国家监管指标 | ISO标准、IATF标准、IEC标准、PMC学术综述、国家金融监管总局 |
| ⭐⭐⭐⭐ 权威 | 专业机构报告 / 行业通用基准 / 头部企业实践 | ASQ质量协会、麦肯锡研究、红海云、Keysight |
| ⭐⭐⭐ 较权威 | 单一机构调研 / 细分领域参考 | 行业博客、细分领域报告 |

## 🔧 使用方法

### 在诊断工具中使用

```bash
# 指定行业指标库路径
python3 scripts/diagnose.py \
  --input goal_data.json \
  --industry-metrics examples/industry-metrics \
  --format html
```

### 匹配逻辑

诊断工具会自动将目标中的指标名称与行业指标库进行匹配：
1. 使用 Jaccard 字符相似度算法
2. 相似度阈值：50%
3. 匹配成功后，将目标值与行业基准值对比
4. 判定偏离程度：远低 / 略低 / 正常 / 略高 / 远高

## 📈 偏离判定标准

| 偏离等级 | 判定条件 | 严重度 |
|---------|---------|--------|
| 远低于基准 | 实际值 < 基准值 × 80% | 高 |
| 略低于基准 | 基准值 × 80% ≤ 实际值 < 基准值 × 95% | 中 |
| 正常范围 | 基准值 × 95% ≤ 实际值 ≤ 基准值 × 105% | - |
| 略高于基准 | 基准值 × 105% < 实际值 ≤ 基准值 × 120% | 低 |
| 远高于基准 | 实际值 > 基准值 × 120% | 中 |

> 注：对于反向指标（如不良率、故障率），高低逻辑相反。

## 🚀 扩展指南

### 新增行业

1. 在 `industry-metrics/` 下创建新行业文件夹
2. 创建三个文件：`战略层指标.md`、`管理层指标.md`、`执行层指标.md`
3. 按照现有格式填写指标内容

### 新增指标

在对应层级的文件中添加指标，确保包含：
- 指标名称
- 基准值
- 合理范围
- 数据来源（战略层）/ 对应上层指标（管理层/执行层）
- 权威性评分（战略层）
- 详细说明
